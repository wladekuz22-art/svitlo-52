# Світло 5.2

Мінісайт та Telegram-сповіщення про зміни **видимого графіка** на https://bezsvitla.com.ua/kyivska-oblast/cherha-5-2.

## Налаштування

1. Завантажте **вміст архіву** до кореня репозиторію GitHub (важливо: папка `.github` має залишитися прихованою папкою з workflow).
2. GitHub → **Settings → Secrets and variables → Actions → New repository secret**. Створіть два секрети: `TELEGRAM_TOKEN` (токен від BotFather) і `TELEGRAM_CHAT_ID` (числовий ID з @userinfobot). Не публікуйте їх у файлах.
3. **Settings → Actions → General → Workflow permissions**: виберіть **Read and write permissions** → Save.
4. **Settings → Pages → Build and deployment**: **Deploy from a branch**, `main`, `/docs` → Save.
5. **Actions → Check electricity schedule → Run workflow**. Перевірте вкладку запуску та повідомлення в Telegram. Після публікації сайт буде за адресою `https://ВАШ-USERNAME.github.io/svitlo-52/`.

Автоматичні запуски плануються кожні 15 хвилин, але GitHub Actions може затримувати або пропускати заплановані запуски. Це не миттєві push-сповіщення з джерела.

## Важливі обмеження

- Сайт може змінити HTML/верстку, тоді автоматичне зчитування перестане працювати. Система не вигадує години, а зберігає останні перевірені дані.
- Скриншот знімається тільки з блоку графіка, якщо він однозначно знайдений. Кольори на скриншоті належать джерелу; система не вгадує, що означають інтервали.
- Порівнюються зображення. Якщо сайт змінив лише оформлення або підпис у блоці, можливе зайве повідомлення.
- Якщо сторінка завтра недоступна, зображення за попередню дату не показується.
- GitHub Pages та репозиторій Public означають, що графіки доступні всім за посиланням. Токен і ID зберігайте лише у Secrets.
